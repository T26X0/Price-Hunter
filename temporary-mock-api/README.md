# TEMPORARY — Price Hunter Mock API

This is a **temporary** Python server for frontend development. It imitates the current Price Hunter backend API while the Spring Boot backend evolves.

Do not add production logic here. The source of truth for the production API remains the Java project in the parent folder.

## What it provides

- `GET /api/products` — returns demo products
- `POST /api/products` — adds a product to temporary in-memory storage
- `GET /health` — confirms that the server is running
- `GET /docs` — interactive API documentation generated by FastAPI

The JSON format mirrors the Java `ProductResponse` contract:

```json
{
  "id": "UUID",
  "name": "Product name",
  "sku": "PRODUCT-SKU",
  "description": "Optional description",
  "createdAt": "2026-08-23T10:00:00Z"
}
```

## Start

From this folder:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8000
```

The API will be available at `http://localhost:8000`.

## For the React frontend

Use this base URL while developing:

```text
http://localhost:8000
```

Later, when the Spring Boot service is ready, replace only the base URL with:

```text
http://localhost:8080
```

Keep endpoints and JSON fields identical in both backends.
